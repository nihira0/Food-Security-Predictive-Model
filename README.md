# Food-Security-Predictive-Model
Smart Food Security and Cultivation Analysis System built with JavaScript using OOP, Data Structures, Algorithms, and Data Visualization to analyze agricultural supply-demand risks.

AgriShield 🌱
Smart Food Security and Cultivation Analysis System

AgriShield is a simulation-based food security analysis system developed using JavaScript. The project models agricultural ecosystems using farmers, crops, and regions to evaluate food supply and demand conditions.

The system predicts food security risks and generates recommendations to support better agricultural planning and resource management.

How It Works
Farmers are assigned crops.
Crops produce yields.
Regional food demand is defined.
Total supply is calculated.
Supply is compared against demand.
Food security risk is classified.
Recommendations are generated.
Results are displayed on a dashboard and chart.
