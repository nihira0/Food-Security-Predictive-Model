# 🌱 AgriShield: Smart Food Security and Cultivation Analysis System

## 📌 Overview

AgriShield is a simulation-based web application designed to analyze food security conditions using predictive modeling and intelligent decision-making techniques. The system evaluates agricultural production and regional food demand to identify potential food shortages, surpluses, and risk levels.

The project demonstrates the practical implementation of Object-Oriented Programming (OOP), Data Structures, Algorithms, and Data Visualization while addressing real-world challenges in agriculture and food security.

---

## 🎯 Objectives

- Analyze food supply and demand relationships.
- Identify food security risks in different regions.
- Classify regions into risk categories.
- Generate recommendations for agricultural planning.
- Demonstrate practical applications of OOP concepts.
- Implement efficient data structures and algorithms.
- Visualize agricultural data through an interactive dashboard.

---

## 🚀 Features

### Food Security Analysis
- Calculates total food supply from crop yields.
- Compares supply against regional demand.
- Detects shortages and surpluses.

### Risk Classification
- 🟢 Low Risk – Supply exceeds demand.
- 🟡 Moderate Risk – Supply is close to demand.
- 🔴 High Risk – Supply is lower than demand.

### Recommendation Engine
- Suggests actions based on food security status.
- Supports proactive agricultural planning.

### Interactive Dashboard
- Clean and user-friendly interface.
- One-click simulation execution.
- Real-time results display.

### Data Visualization
- Supply vs Demand comparison chart.
- Easy-to-understand graphical insights using Chart.js.

## 📊 How the System Works

1. Farmers are assigned crops.
2. Each crop produces a yield value.
3. A region is assigned a food demand value.
4. The system calculates total food supply.
5. Supply is compared with demand.
6. Risk levels are determined.
7. Recommendations are generated.
8. Results are displayed on the dashboard and chart.
